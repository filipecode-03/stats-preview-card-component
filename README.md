# 📈 Stats Preview Card Component – Frontend Mentor Challenge

### 📌 About the Project

This project consists of a **card component for displaying statistics**, developed from a challenge on the **Frontend Mentor** platform.
The goal was to reproduce the proposed layout using exclusively **HTML and CSS**, focusing on semantic structuring, visual organization, and fidelity to the original design.
The project reinforces essential front-end development fundamentals without the use of JavaScript.

### 🛠️ Technologies Used

[![My Skills](https://skillicons.dev/icons?i=html,css)](https://skillicons.dev)

### 🧠 Learnings

During the development of this project, it was possible to:

- Practice creating visual components with **semantic HTML**.
- Improve **layout and styling skills with CSS**.
- Work with visual hierarchy, colors, and typography.
- Emphasize attention to detail to represent information clearly.
